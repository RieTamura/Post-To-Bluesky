# Post To Bluesky - Obsidianプラグイン

言語：**日本語** | [English](./README_EN.md)

ObsidianからBluesky（ブルースカイ）に投稿できるプラグインです。投稿モーダルを開いて自由に内容を作成し、Blueskyに投稿できます。

## 主な機能

### 📝 投稿機能

- **投稿作成**: 投稿モーダルを開いて自由に内容を作成してBlueskyに投稿

### ✍️ Markdown記法で書く（既定はオフ）

- `[表示テキスト](URL)` を **本物のリンクとして投稿**（長いURLで300字を圧迫しません）
- 太字・斜体・見出し・箇条書き・コード・引用などの**記号を取り除いて**投稿
- `[[ノート名|表示名]]` は表示名だけを残します
- Bluesky の投稿はプレーンテキストのため、**太字や斜体そのものは表現できません**（後述）

### 📄 下書きノートから投稿

- vault内のノートをそのまま下書きとして使用
- frontmatter に `type: bluesky-draft` を書いたノートが下書き一覧に表示される
- 一覧には文字数バッジを表示（300字超は赤色で警告）
- 投稿するとそのノート自体が投稿済みに更新される（後述）

### 💾 書きかけを下書きノートに残す

- 投稿せずに作成画面を閉じると、下書きノートに残すか確認します（既定: オン）
- 「下書きを作成」「破棄」「編集に戻る」の3択。Esc や外側クリックは「編集に戻る」扱いです
- 下書きノートから開いていた場合は、**そのノートを更新**します（同じ内容のノートが増えません）
- 添付していた画像も一緒に残ります

### 📋 投稿履歴ノートの自動作成

- 投稿成功時に、本文・日時・投稿URL・タグを持つノートを自動作成（既定はオフ）
- 本文中のハッシュタグは frontmatter の `tags` に移される
- 保存先フォルダはフォルダサジェスト付きの入力欄で選択

### 🔗 ノートの紐づけ

- 下書きノート・履歴ノートの frontmatter に、任意のノートへのリンクを自動で追加
- 紐づけ先は下書き用・履歴用を別々に指定でき、ノートサジェスト付きの入力欄で選択
- `{{date:YYYY-MM-DD}}` のような日付変数が使えるので、その日のデイリーノートに紐づけることも可能

### 📱 モバイル対応

- iOS / Android のObsidianアプリでも投稿可能
- 画像添付を含め、デスクトップと同じ機能が使えます
- 作成画面を開いた時点ではキーボードを出しません（本文をタップすると出ます）。
  開いた直後から画像ボタンや文字数カウンタが見える状態にするためです
- 本文を入力中はヘッダーに **キーボードを閉じるボタン** が出ます。これを押すと
  キーボードの裏に隠れていた画像ボタン・絵文字ボタン・文字数カウンタを操作できます

### 🖼️ 画像添付

- 最大4枚までの画像を添付可能（デスクトップ・モバイル共通）
- 添付元は2通り。**vault内の画像から選ぶ**か、**端末のファイル/写真から選ぶ**か
- 添付した画像は下書きノート・履歴ノートに `![[...]]` として記録されます
- 下書きノートに埋め込んだ画像は、そのノートから投稿するとそのまま添付されます
- 画像のアスペクト比を自動調整し、Blueskyの容量上限に収まるよう自動で圧縮します

### 😊 絵文字ピッカー

- カテゴリ別に整理された絵文字選択
- 感情、手、ハート、自然、食べ物、アクティビティなどの分類
- ホットキーで素早くアクセス

### ⚙️ カスタマイズ設定

- Blueskyアカウントの設定（ハンドル、アプリパスワード）
- デフォルトハッシュタグの設定
- Markdown記法を変換して投稿するかどうか
- ネットワークタイムアウトの調整
- カスタムホットキーの設定
- 下書きノートの判定条件（frontmatterのキー名と値）
- 投稿せずに閉じたときの下書き保存の確認と、その保存先フォルダ
- 投稿履歴ノートの保存有無と保存先フォルダ
- 紐づけ先ノートと、リンクを書き込むプロパティ名
- 端末から選んだ画像をvaultに保存するかどうか

### ⌨️ ホットキー設定

#### Modキーについて

`Mod`キーは、使用しているオペレーティングシステムに応じて自動的に適切なキーに置き換わります：

- **macOS**: `⌘`（Commandキー）
- **Windows/Linux**: `Ctrl`キー

#### ホットキーのカスタマイズ

投稿モーダル内で以下の操作にホットキーを設定できます：

| 機能 | デフォルト |
|------|-----------|
| 投稿送信 | 設定なし |
| 画像追加 | 設定なし |
| 絵文字ピッカー | 設定なし |
| キャンセル | 設定なし |

各ホットキーは設定画面で自由に設定できます。例：`Mod+Enter`、`Mod+I`、`Mod+E`など

## インストール方法

### 手動インストール

1. このリポジトリをクローンまたはダウンロード
2. `main.js`、`styles.css`、`manifest.json`を`.obsidian/plugins/post-to-bluesky/`フォルダにコピー
3. Obsidianを再起動
4. Obsidianの「設定→コミュニティプラグイン」でSafe modeをオフにし、Community pluginsを有効化
5. 設定でプラグインを有効化

### 開発環境でのセットアップ

```bash
# 依存関係のインストール
npm install

# 開発モードでのコンパイル
npm run dev
```

## 使用方法

### 1. 初期設定

1. Obsidianの設定を開く
2. 「Post To Bluesky」の設定タブを選択
3. Blueskyのハンドルとアプリパスワードを入力
   - アプリパスワードはObsidianのキーチェーンに保存されます（`data.json` には書かれません）
4. 必要に応じてデフォルトハッシュタグを設定

### 2. 投稿の作成

- **コマンドパレット**から「Open post composer」を実行
- **リボンアイコン**（送信アイコン）をクリックして新規投稿を作成

### 2-0. 画像を添付する

投稿モーダルの画像ボタン（またはコマンド「Add image」）を押すと、添付元を選ぶメニューが出ます。

- **vault内の画像から選ぶ**: vault内の画像を新しい順に検索して選びます。
  すでにvaultにあるファイルなので、そのままノートに記録されます
- **端末から選ぶ**: OSのファイル/写真ピッカーから選びます。
  「端末から選んだ画像をvaultに保存」がオンなら、投稿後にvaultへ取り込まれて
  ノートに埋め込まれます

添付できるのは1投稿あたり最大4枚です。画像を添付すると、リンクカード（URLのプレビュー）は
表示されなくなります。Bluesky側の仕様で、画像とリンクカードは同時に投稿できないためです。

投稿に成功すると、添付した画像は下書きノート・履歴ノートの本文末尾に
`![[画像のパス]]` として記録されます。

### 2-1. 下書きノートから投稿する

1. 任意のノートの frontmatter に下書き判定用のプロパティを書きます。

   ```yaml
   ---
   type: bluesky-draft
   ---
   今日の投稿内容をここに書きます。
   ```

   値は配列でも構いません（例: `type: [bluesky-draft, note]`）。
   キー名と値は設定で変更できます。

2. **コマンドパレット**から「Post from draft notes」を実行するか、
   **リボンアイコン**（ドキュメントアイコン）をクリックします。
3. 下書き一覧から投稿したいノートを選ぶと、frontmatterを除いた本文が
   投稿モーダルにセットされます。300字を超えている場合は警告が出るので、
   モーダル上で編集してから投稿してください。

   ノートに画像が埋め込まれている場合（`![[写真.png]]`）、その画像は**添付画像として
   引き継がれ、本文からは取り除かれます**。埋め込み記法をそのまま投稿すると、
   画像が付かないのに文字数だけ消費してしまうためです。下書き一覧には、
   何枚引き継がれるかが画像アイコンとともに表示されます。
4. 投稿に成功すると、その下書きノートの frontmatter が次のように更新されます。

   ```yaml
   ---
   type:                      # bluesky-draft が取り除かれる
     - note                   # 他の値はそのまま残る
   bluesky_posted: true       # チェックボックスとして表示される
   posted_at: 2026-07-26T17:30:00
   url: https://bsky.app/profile/xxx.bsky.social/post/3kabc...
   ---
   ```

   `bluesky_posted` にチェックが入ったノートは下書き一覧から消えます。
   下書き値しか入っていなかった場合はキーごと削除されます。

   なお、下書きから投稿した場合は**履歴ノートを別途作成しません**。
   そのノート自体が投稿の記録になるため、同じ投稿が二重にノート化されるのを防いでいます。

   投稿モーダルで**新しく足した**画像は、下書きノートの末尾に `![[...]]` として追記されます。
   もともとノートに埋め込まれていた画像は既に本文にあるため、追記されません。

### 2-2. 投稿履歴ノートを自動作成する

設定で「投稿履歴を保存」をオンにすると、投稿モーダルから直接投稿した際に
1投稿=1ノートの履歴が保存先フォルダに作られます。

```yaml
---
type: bluesky-posted
bluesky_posted: true
posted_at: 2026-07-26T17:30:00
url: https://bsky.app/profile/xxx.bsky.social/post/3kabc...
tags:
  - Obsidian
---
投稿した本文が残ります。
```

- ファイル名は投稿日時から生成されます（例: `2026-07-26 1730.md`）
- 本文中のハッシュタグは `tags` に移され、本文からは取り除かれます。
  そのため履歴ノートの本文は投稿原文と完全には一致しません。原文は `url` から辿ってください
- 保存先フォルダが存在しない場合は自動作成されます
- 履歴の保存に失敗しても投稿自体は成功として扱い、通知のみ表示します

### 2-3. ノートを他のノートに紐づける

設定で紐づけ先ノートを指定しておくと、下書きノート・履歴ノートの frontmatter に
そのノートへのリンクが自動で追加されます。紐づけ先のバックリンク欄に投稿が集まるので、
デイリーノートやMOCから当日の投稿をたどれるようになります。

```yaml
---
posted_at: 2026-07-27T17:50:42
url: https://bsky.app/profile/xxx.bsky.social/post/3kabc...
related: "[[01_data/2026/07/2026-07-27]]"   # 自動で追加される
---
```

- 紐づけ先は**下書き用・履歴用で別々に指定**できます。空欄にすればその側は紐づけません
- プロパティ名は設定で変更できます（既定: `related`）
- 紐づけ先ノート自体は書き換えません。リンクは投稿側のノートにだけ書かれます
- 既に同じプロパティに値が入っている場合は**上書きせず**、既存の値を残したまま配列に追加します。
  同じリンクが既にあるときは何もしないので、再投稿しても重複しません

#### 日付変数を使う

紐づけ先の欄には日付変数を書けます。書式は Obsidian のデイリーノート／テンプレートの
コアプラグインと同じ記法です。

```
01_data/{{date:YYYY/MM/YYYY-MM-DD}}   →   related: "[[01_data/2026/07/2026-07-27]]"
```

| 変数 | 展開結果 |
|------|----------|
| `{{date}}` | `2026-07-27`（既定書式 `YYYY-MM-DD`） |
| `{{date:YYYY/MM}}` | `2026/07` |
| `{{time:HHmm}}` | `1750`（既定書式は `HH:mm`。パスに使う場合は `HHmm` を推奨） |

- 1つの設定に複数の変数を書けます
- 展開の基準は**投稿日時**（`posted_at` と同じ時刻）です
- `{{date:gggg-[W]ww}}` のようなエスケープ記法も使えます

#### 紐づけ先のノートが存在しない場合

書き方によって挙動が変わります。

- **変数入り**: 展開先のノートが無くても**未作成リンクとして書きます**。
  その日のデイリーノートを後から作れば自動でリンクが繋がります
- **固定パス**: 実在しなければリンクを付けず、通知のみ表示します。
  紐づけ先をリネームした場合やパスの打ち間違いに気づけるようにするためです

いずれの場合も投稿自体は成功として扱われます。

### 2-4. Markdown記法で投稿文を書く

設定の「Markdown記法を変換して投稿」をオンにすると、投稿文に書いた Markdown を
Blueskyに送る前に平文へ変換します（既定はオフ）。

**先に知っておいてください。Blueskyの投稿はプレーンテキストです。**
リンク・メンション・ハッシュタグ以外の装飾を持つ仕組み（facet）が存在しないため、
**太字や斜体そのものは投稿できません**。このプラグインができるのは
「リンク記法を本物のリンクに変える」ことと「表現できない記号を取り除く」ことの2つです。

| 書いたもの | 投稿されるもの |
|---|---|
| `[ここ](https://example.com/長いURL)` | **ここ**（クリックできるリンクになります） |
| `**重要**` / `*強調*` / `~~取り消し~~` / `==強調==` | 重要 / 強調 / 取り消し / 強調（記号のみ除去） |
| `## 見出し` | 見出し |
| `- 箇条書き` | ・箇条書き |
| `1. 番号付き` | 1. 番号付き（そのまま） |
| `` `コード` `` / ```` ```コードブロック``` ```` | コード / コードブロック（囲みのみ除去） |
| `> 引用` | 引用 |
| `[[ノート名]]` / `[[ノート名\|表示名]]` | ノート名 / 表示名 |
| `<https://example.com>` | https://example.com |
| `\*記号のまま\*` | \*記号のまま\*（バックスラッシュでエスケープ） |

#### BlueskyでのMarkdown記法の見え方

変換はすべての記法に効きますが、**Bluesky上で見た目に結果が残るのはリンクと箇条書きの2つだけ**です。

| 見え方 | 記法 |
|---|---|
| **見た目に残る** | `[表示テキスト](URL)`（青いリンクになる）、`- 箇条書き`（`・` が残る）、`1. 番号付き`（そのまま） |
| **記号が消えるだけ** | `**太字**` / `*斜体*` / `## 見出し` / `> 引用` / `~~取り消し~~` / `==ハイライト==` / `` `コード` `` / コードブロック |

太字や見出しが平文になるのは、**変換の失敗ではなく仕様どおりの結果**です。
Blueskyの投稿レコードが持てるのはプレーンテキストと facet（リンク・メンション・ハッシュタグ）だけで、
装飾用の facet が規格として存在しないため、どのクライアントでも表現できません。

そのためこの設定の価値は「装飾を付けること」ではなく、**Obsidianで普段どおり書いたノートを
そのまま下書きにしても、投稿に記号のゴミが残らない**ことにあります。
オフのままだと `**太字**` は記号ごと投稿され、300字の枠も4文字ぶん余計に消費します。

補足:

- **文字カウンターは変換後の文字数を数えます。** 記号が消えるぶん、表示は入力より短くなります
- `[表示テキスト](URL)` を書いた場合、リンクカード（URLプレビュー）はそのURLから作られます
- **`snake_case` や `2*3*4` は変換されません。** 単語の内側にある記号は記法として扱わないため、
  意図せず記号が消えることはありません
- 履歴ノート・下書きノートには**入力したままのMarkdown**が残ります（変換後の平文ではありません）
- オフのままだと、`**` や `#` がそのまま投稿され、文字数も消費します

### 2-5. 投稿せずに閉じたときに下書きへ残す

書きかけのまま作成画面を閉じると、下書きノートに残すか確認します（既定: オン）。

- **下書きを作成**: 「下書きノートの保存先」に新しいノートを作ります。
  frontmatter に下書き判定用のプロパティが付くので、そのまま下書き一覧に出ます
- **破棄**: 何もしません
- **編集に戻る**: 本文と添付画像を引き継いで作成画面を開き直します。
  **Esc や外側クリックで閉じた場合もこれと同じ扱い**です（書きかけを黙って捨てないため）

下書きノートから開いていた場合は「下書きを更新」になり、**元のノートを書き換えます**。
このとき frontmatter は変更しません。添付画像は本文の末尾にまとめて埋め込み直されます
（作成画面では埋め込みを本文から外して画像として扱っているため、元の位置には戻せません）。

確認が出ないのは次の場合です。

- 本文が空で画像も添付していない
- 開いた時点から何も変えていない（下書きノートから開いてそのまま閉じた場合など）
- 「投稿せずに閉じたとき下書き保存を確認」をオフにしている

### 3. 投稿の編集

- テキストの入力と編集
- 画像の追加（最大4枚）
- 絵文字の挿入
- ハッシュタグの追加

### 4. 投稿の送信

- 設定したホットキーで投稿を送信（例：`Mod+Enter`）
- または投稿ボタンをクリック

## 技術仕様

### 対応環境

- **Obsidian**: 1.11.5以上（v0.6.0以降。アプリパスワードをキーチェーンに保存するため）
  - v0.5.1以前は1.8.7以上でした
- **プラットフォーム**: デスクトップ（Windows、macOS、Linux）とモバイル（iOS、Android）
  - 画像添付を含め、モバイルでもデスクトップと同じ機能が使えます（v0.4.0以降）
- **言語**: TypeScript

### 主要な技術

- **Obsidian Plugin API**: プラグインの基盤機能
- **Bluesky API**: 投稿と認証の処理
- **TypeScript**: 型安全性と開発効率の向上
- **ESBuild**: 高速なTypeScriptコンパイル

### アーキテクチャ

- **モジュール化**: 機能別にファイルを分割
- **型安全性**: インターフェースと型定義による堅牢性
- **エラーハンドリング**: 包括的なエラー処理とユーザーフィードバック

## 設定項目

### 基本設定

- **Handle**: Blueskyのユーザーハンドル（例： `@username.bsky.social`）
- **アプリパスワード**: Blueskyのアプリパスワード。Obsidianのキーチェーンに保存されます
  - 入力欄で新しいシークレットを作るか、既に登録済みのシークレットを選びます
  - 保存済みの値は **設定 → キーチェーン** から確認・削除できます
- **Default Hashtags**: デフォルトで追加されるハッシュタグ
  - 下書きノートから開いた場合は、300字の上限を圧迫しないよう自動挿入しません
- **Markdown記法を変換して投稿**: `[表示テキスト](URL)` をリンクとして投稿し、
  太字・見出し・箇条書きなどの記号を取り除くか（既定: **オフ**）
  - オフを既定にしているのは、Blueskyには太字が無いため `*` を記号として
    見せるつもりで書く人がいるためです。更新だけで投稿内容が変わらないようにしています
  - 変換の内容は[使用方法 2-4](#2-4-markdown記法で投稿文を書く)を参照してください
- **Network Timeout**：ネットワークリクエストのタイムアウト時間（ミリ秒、既定：15000ms）

### 下書き設定

- **下書きプロパティ名**: 下書きノートを識別するfrontmatterのキー名（既定: `type`）
- **下書き判定値**: 上記キーに対応する値。この値を持つノートが下書き一覧に表示されます（既定: `bluesky-draft`）
- **投稿せずに閉じたとき下書き保存を確認**: 書きかけがあるまま作成画面を閉じたときに、
  下書きノートへ残すか尋ねるか（既定: オン）
- **下書きノートの保存先**: 上記で作成する下書きノートのフォルダ（既定: `Bluesky Drafts`）
  - vault内フォルダのサジェスト付き入力欄です。存在しないフォルダ名を入力した場合は保存時に自動作成されます
  - 「投稿せずに閉じたとき下書き保存を確認」がオフのときはグレーアウトします

### 投稿履歴設定

- **投稿履歴を保存**: 投稿成功時に履歴ノートを自動作成するか（既定: オフ）
- **履歴ノートの保存先**: 履歴ノートを作成するフォルダ（既定: `Bluesky Posts`）
  - vault内フォルダのサジェスト付き入力欄です。存在しないフォルダ名を入力した場合は投稿時に自動作成されます
  - 「投稿履歴を保存」がオフのときはグレーアウトします

### 紐づけ設定

- **紐づけプロパティ名**: 紐づけ先へのリンクを書き込むfrontmatterのキー名（既定: `related`）
- **下書きノートの紐づけ先**: 下書きから投稿したとき、そのノートに紐づけるノート（既定: 空欄＝紐づけなし）
- **履歴ノートの紐づけ先**: 作成した履歴ノートに紐づけるノート（既定: 空欄＝紐づけなし）
  - 「投稿履歴を保存」がオフのときはグレーアウトします

紐づけ先の2つはvault内ノートのサジェスト付き入力欄です。`{{date:YYYY-MM-DD}}` などの
日付変数を書くこともできます（[使用方法 2-3](#2-3-ノートを他のノートに紐づける)を参照）。

### 画像設定

- **端末から選んだ画像をvaultに保存**: 端末から添付した画像をvaultに取り込み、
  下書きノート・履歴ノートに埋め込むか（既定: オン）
  - 保存先はObsidian本体の**「添付ファイルの保存先」設定に従います**。プラグイン独自の
    フォルダ設定はありません
  - オフにすると投稿はできますが、ノートには画像が残りません
  - **vault内の画像を選んだ場合は、この設定に関わらずノートに記録されます**
    （既にvaultにあるファイルなので、新たな保存が発生しないため）

### ホットキー設定

- **Cancel**: 投稿をキャンセルするホットキー（デフォルト：なし）
- **Post**: 投稿を送信するホットキー（デフォルト：なし）
- **Add Image**: 画像を追加するホットキー（デフォルト：なし）
- **Emoji**: 絵文字ピッカーを開くホットキー（デフォルト：なし）

#### Modキーの動作

- macOSでは `⌘` (Command)キーとして動作
- Windows/Linuxでは `Ctrl`キーとして動作
- プラットフォームに応じて自動的に適切なキーが使用される

### セキュリティとプライバシー

- **アプリパスワードはObsidianのキーチェーンに保存されます**（**設定 → キーチェーン** で確認・削除できます）。vault内の `data.json` には書かれません。
- Obsidian 1.11.5以降、キーチェーンの中身はOSの暗号化機構で保護されます（macOSはキーチェーン、WindowsはDPAPI）。**Linuxでは kwallet / kwallet5 / kwallet6 / gnome-libsecret のいずれかが必要**です。
- v0.5.1以前から更新した場合、**初回起動時に平文のアプリパスワードが自動でキーチェーンへ移され、`data.json` からは削除されます**（移行時に通知が出ます）。移行前に作った `data.json` のバックアップやGit履歴には平文が残っているため、必要なら消してください。
- キーチェーンは**すべてのプラグインで共有**されます。他のプラグインもシークレットIDを列挙して値を読めるため、守れるのは「vaultの同期・共有・ディスクからの漏洩」であって、悪意あるプラグインからではありません。
- キーチェーンは**デバイス間で同期されません**。端末ごとにアプリパスワードの設定が必要です。
- `data.json` にローカル保存される情報：ハンドル、シークレットID、デフォルトハッシュタグ、ネットワークタイムアウトなどの設定（保存場所は `.obsidian/plugins/post-to-bluesky/data.json`）。
- 通常のBlueskyアカウントのパスワードではなく、[アプリパスワード](https://bsky.app/settings/app-passwords)を使ってください。アプリパスワードはBlueskyの設定からいつでも失効できます。
- 漏洩が疑われる場合は、Blueskyの設定でただちにアプリパスワードを失効させてください。
- 画像は送信時に読み込んでアップロードするだけで、投稿後にキャッシュはしません。
- データの送信先はBluesky / AT Protocolのエンドポイント（`bsky.social` など）のみで、HTTPS（TLS）を使用します。
- 通信中：HTTPSで暗号化。保存時：OSやディスクの暗号化のみに依存します。
- ネットワークタイムアウト：既定15000ms（変更可）。レート制限エラー時の自動リトライはありません。
- レート制限や失敗時は通知が出ます。時間をおいて手動で再送してください。

## トラブルシューティング

### よくある問題

1. **ログインできない**: アプリパスワードが正しく設定されているか確認
   - **注意**: このプラグインを使用するには、Blueskyアカウントとアプリパスワードが必要です。アプリパスワードはBlueskyの設定画面で生成できます。

2. **投稿が失敗する**: ネットワーク接続とBlueskyのサービス状況を確認

3. **ホットキーが動作しない**: 設定画面でホットキーが正しく設定されているか確認

4. **下書き一覧にノートが出てこない**: 次の2点を確認してください
   - frontmatter のキー名と値が設定と一致しているか（既定は `type: bluesky-draft`）
   - `bluesky_posted` にチェックが入っていないか。投稿済みのノートは一覧から除外されます。
     再度下書きとして扱いたい場合は、`bluesky_posted` を外したうえで
     `type` に `bluesky-draft` を書き戻してください

5. **投稿した文に `**` や `#` が残っている**: 「Markdown記法を変換して投稿」がオフです
   （既定はオフ）。設定でオンにしてください

6. **投稿を閉じても下書き保存を聞かれない**: 開いた時点から本文が変わっていない場合と、
   「投稿せずに閉じたとき下書き保存を確認」がオフの場合は確認しません

### ログの確認

- 開発者ツールの開き方：メニュー「表示→開発者ツールを切り替え」
  - Windows / Linux：`Ctrl+Shift+I` または `F12`
  - macOS：`Cmd+Option+I`
- 「Console」タブ：エラーメッセージや `console.log` 出力を確認
- 「Network」タブ：APIリクエストの成功/失敗ステータスやレスポンス本文を確認

## 既知の制限

- 画像添付は最大4枚（Bluesky側仕様）
- 動画の添付には対応していません
- アニメーションGIFは1コマ目の静止画として投稿されます（Blueskyへ送る前に再エンコードするため）
- SVGは添付できません（画像として読み込めないため一覧に出ません）
- 画像をドラッグ&ドロップ・貼り付けで追加することはできません（ボタンまたはコマンドから選択します）
- 投稿文字数は最大300文字（超えると送信前にエラー表示）
- レート制限時は投稿失敗として通知し自動再試行なし（数分待って再送）
- **Blueskyの投稿に太字・斜体・見出しはありません。** 投稿レコードが持てるのは
  プレーンテキストと facet（リンク・メンション・ハッシュタグ）だけで、装飾のための
  facet が規格上存在しないためです。Markdown変換は「リンク記法をリンクに変える」
  「表現できない記号を取り除く」までしかできません
- `![[別のノート]]` のような画像以外の埋め込みは、Markdown変換をオフにしていると
  記法のまま投稿されます（オンなら表示名だけが残ります）
